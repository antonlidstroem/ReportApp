Place chart.umd.min.js here for Chart.js PDF support.

Download from: https://cdn.jsdelivr.net/npm/chart.js@4.4.0/dist/chart.umd.min.js

OR run this command from the project root:
  curl -o wwwroot/chart.umd.min.js https://cdn.jsdelivr.net/npm/chart.js@4.4.0/dist/chart.umd.min.js

The file must be present for PDF exports with charts to render correctly.
